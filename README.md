# Chíp Chíp (funedu)

Ứng dụng học viết cho trẻ em, linh vật Chíp Chíp.

- `app/` — dự án mới (Flutter), mã gói `com.ibme.funedu`.
- `tools/` — công cụ hỗ trợ (xử lý bộ ảnh, v.v.).
- `docs/superpowers/specs/` — spec thiết kế.
- `docs/superpowers/plans/` — kế hoạch triển khai.
- `docs/phase0/` — tài liệu giai đoạn 0.
- Mã app cũ đã bỏ khỏi nhánh này; tra trong lịch sử git (nhánh `new-web`, `develop`).
